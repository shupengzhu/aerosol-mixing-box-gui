# SCRAM Box (v2)

Box model of the CESM-SCRAM aerosol kernel (hetfix) with ISORROPIA v1 or ISORROPIA II v2.3,
no cfg files, and a local web interface.

- `kernel/`   kernel snapshot build (`build_kernel.sh`), Fortran driver, species tables, CMAQ speciation, LUT fetch
- `scrambox/` Python package: case compiler and runner, scenario library, post-processing
  (optics, CCN, heterogeneous uptake, identical to CESM-SCRAM), experiment sets, web server and front end
- `scenarios/` built-in scenarios, generated by `tools/make_scenarios.py`
- `docs/case_format.md` case format and implementation notes
- `tests/` smoke, sub-step, coagulation, scenario and post-processing checks

## Build

```bash
CAM_SRC=<CESM-SCRAM CAM component on branch component/cam-isorropia2-crustal> ISO_VARIANT=v1  bash kernel/build_kernel.sh
CAM_SRC=<...> ISO_VARIANT=v23 bash kernel/build_kernel.sh   # needs isorropia2/ generated by prepare_isorropia2.py
SCRAM_SRC=<CESM-SCRAM source tree> bash kernel/fetch_luts.sh
python3 tools/make_scenarios.py
```

Requirements: gfortran with OpenMP, BLAS, Python 3.10+ with numpy and netCDF4.

## Use

```bash
python3 -m scrambox serve --port 8765        # then ssh -L 8765:localhost:8765 <server>, open http://localhost:8765
python3 -m scrambox run scenarios/urban_plume_aging.json -o runs/up    # command line
python3 -m scrambox classes --preset NC11
```

User data (runs, experiment sets, saved scenarios) go to `SCRAMBOX_USER_DIR` (default `~/.scrambox`).

## PartMC mode

`/?model=partmc` (or the SCRAM/PartMC switch in the top bar) runs the same scenario particle-resolved
with PartMC plus the SCRAM per-particle thermodynamics (`pmc_scram_thermo`: dynamic ISORROPIA,
CESM VBS SOA). Results are projected onto the scenario's size × class grid, so every SCRAM result view
applies; a "particle-resolved" tab adds the per-particle truth (mixing-state index χ, κ-Köhler CCN,
BC coating, 2-D histograms). The experiment preset "SCRAM NC1/NC6/NC11 vs PartMC" compares the grids
with the truth. PartMC is not bundled: point `PARTMC_V23` / `PARTMC_V1` at builds of PartMC with the
SCRAM thermodynamics module. Batch benchmark: `python3 tools/partmc_experiment.py <scenario>`.

## Shared server

With an access code the server asks every user to sign in (access code + name) and keeps a
separate workspace per name, with compute limits (`SCRAMBOX_MAX_ACTIVE`, `SCRAMBOX_MAX_COST`,
`SCRAMBOX_MAX_VARIANTS`, `SCRAMBOX_RUN_TIMEOUT`). `tools/service.sh` runs it persistently on
127.0.0.1 (cron watchdog, no root); publish it through an HTTPS reverse proxy, e.g.

```bash
tools/service.sh set-code <code> && tools/service.sh start && tools/service.sh install-cron
sudo tailscale funnel --bg 8765
```

User guide (Chinese): [docs/使用说明.md](docs/使用说明.md).

## Standalone package

`bash tools/package_standalone.sh` writes `dist/scram-box-<date>.tar.gz` with statically linked
kernels (no Fortran runtime needed on the target), the Python package, web interface, scenarios,
species tables and LUTs; unpack, `pip install -r requirements.txt`, run `./scram-box` and open
http://localhost:8765. The ISORROPIA II v2.3 kernel is included only with `INCLUDE_V23=1`
(licence: research use, no redistribution).
ISORROPIA II sources are licensed for research use and are not redistributed; they are generated
locally from the EPFL distribution by `isorropia2/prepare_isorropia2.py` in the CESM-SCRAM branch.
