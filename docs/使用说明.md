# SCRAM Box 使用说明

SCRAM Box 是 SCRAM 气溶胶内核的箱模型，可在浏览器里设置并运行粒径 × 组成分辨的
气溶胶演变，比较不同混合态（颗粒类群）设置对光学、云活化和非均相化学的影响。
热力学可选 ISORROPIA II v2.3（含 Ca、K、Mg）、ISORROPIA v1（SCRAM 修订版）或不用 ISORROPIA（no-ISO）。

---

## 1. 两种使用方式

### 1.1 使用课题组共享服务器（推荐给学生）

1. 浏览器打开导师给的网址（形如 `https://node78.….ts.net/`）。
2. 输入**访问码**和**你的名字**。名字决定你的工作区：下次用同一个名字登录，就能看到之前的运行记录和自定义情景。
3. 共享服务器有限额（防止一个人占满机器）：
   - 每人同时最多 3 个运行或实验组；
   - 单次运行规模上限：内核调用次数 × 粒径段数 × 类群数 ≤ 2×10⁷
     （例如 24 h、10 s 子步长、16 粒径段 × 6 类群约 8×10⁵，远低于上限）；
   - 单次运行最长 1 小时；实验组最多 10 个变体。
   超出限额时界面会提示原因；更大的计算请用单机版。

### 1.2 单机版（自己的 Linux 电脑或服务器）

要求：Linux x86-64，Python ≥ 3.10。内核已静态链接，不需要安装 Fortran 编译器。

```bash
tar xzf scram-box-<日期>.tar.gz
cd scram-box-<日期>
python3 -m pip install --user -r requirements.txt     # numpy、netCDF4
./scram-box                                            # 默认 http://127.0.0.1:8765
```

- 在本机浏览器打开 http://127.0.0.1:8765 。
- 若装在远程服务器上，在自己电脑上建隧道后再打开同一地址：`ssh -L 8765:localhost:8765 <服务器>`
- 换端口：`./scram-box --port 8800`
- 数据（运行记录、自定义情景）默认存放在 `~/.scrambox`，可用环境变量 `SCRAMBOX_USER_DIR` 改。
- 命令行运行（不开界面）：
  `python3 -m scrambox run scenarios/urban_plume_aging.json -o runs/up`
- 把单机版开给几个人共用：设置访问码再启动，界面就会要求登录，并为每人分开工作区：
  `SCRAMBOX_ACCESS_CODE=<访问码> ./scram-box --host 127.0.0.1`

## 2. 界面总览

顶栏有六个标签页，从左到右基本就是一次模拟的流程。右上角可切换中文/English 和深色模式。

| 标签页 | 作用 |
|---|---|
| ① 情景 | 从情景库选择典型情景，查看背景浓度与排放；载入编辑器；另存为自己的情景 |
| ② 配置 | 内核与过程、环境与时间、物种与组、颗粒类群、粒径段 |
| ③ 初始与排放 | 初始颗粒与气体、颗粒排放、气体源、时间廓线（全部用表格填写） |
| ④ 后处理 | 光学与辐射、云活化（CCN）、非均相化学的选项 |
| ⑤ 运行与结果 | 提交运行、查看进度、各类结果图 |
| ⑥ 对比实验 | 以当前配置为基准做多组变体（如 NC1/NC6/NC11、v1/v2.3）并对比 |

编辑中的配置会自动保存在浏览器里，刷新页面不会丢。

右上角的 **SCRAM 箱模型 / PartMC 粒子分辨** 切换运行所用的模型（见第 9 节）；
也可直接打开 `<网址>/?model=partmc` 进入 PartMC 版界面。

## 3. 情景库

搜索框可按名称、标签或描述搜索，结果按类别分组。选中后，下方信息面板显示：

- 环境（温度、湿度、气压、光解、稀释、时长、子步长、内核调用次数）；
- 背景颗粒（数浓度、PM1/PM2.5/PM10、各物种质量）与背景气体；
- 颗粒排放与气体源；
- 文献出处和转换说明。

点 **载入编辑器** 后才写入当前配置，之后可以在各标签页修改。
**将当前配置存为我的情景** 会保存到你的工作区，出现在“我的情景”类别里。

| 情景 | 内容 |
|---|---|
| 最简教学案例 | 新鲜 BC 与硫酸盐凝并 1 h，看数浓度从纯组分类群进入混合类群 |
| GMD hazy 冷凝 / 凝并+冷凝 | Zhu et al. (2015) 验证算例 |
| GMD 巴黎 A–D | 旧版 BoxApp 的巴黎参考场景（仅排放 / 凝并 / 冷凝 / 全过程） |
| 城市羽流老化 | 仿 PartMC urban plume：交通与烹饪排放、稀释、白天光化学生成 H2SO4/HNO3/SOA，BC 逐步被包覆 |
| 海盐 + 硝酸盐 | 海盐与污染大陆气团混合，HNO3 置换氯（氯亏损） |
| 沙尘 + 地壳离子 | 沙尘与污染气体混合，RH 30→85 %；v2.3 中 Ca/K/Mg 参与热力学，v1 中沙尘为惰性 |
| 夜间 N2O5 与 ClNO2 | 沿海夜间在线 N2O5 非均相吸收，生成 HNO3 和 ClNO2 |

## 4. 配置

### 4.1 内核与过程
- **热力学（ISORROPIA）**：v2.3 / v1 / 不使用。
- **气粒分配方案**：动态（按颗粒表面蒸汽压，非平衡）或整体平衡。
- **凝并、冷凝/蒸发、成核** 开关；求解器、再分配方法等默认取 默认配置。
- **在线 N2O5 非均相吸收**：
  - 按生成速率（稳态 [N2O5] = P/(k + k_other)）或给定浓度两种方式；
  - 每步由当前颗粒计算吸收速率，产物 HNO3 进入气相，ClNO2 消耗颗粒氯。

### 4.2 环境与时间
- 温度、湿度、气压、J(NO2)、稀释速率；勾选“环境随时间变化”可逐时填表。
- **内核子步长**：留空时自动取默认值。
  - 动态 ISORROPIA（非平衡）用 10 s；
  - no-ISO 和整体平衡用 600 s；
  - 可以手动改。子步长越短越准确，但越慢。

### 4.3 物种与组
- 显示内核物种表：组、密度、分子量、κ、对应的冷凝气体。
- 可添加**自定义物种**（惰性）：选择所属组，填写密度、分子量、κ。

### 4.4 颗粒类群
- 预设 NC1（内混）、NC6、NC11，或自定义各组比例界限。
- 页面实时显示生成的类群及每个类群的组成区间。

### 4.5 粒径段
- 对数等分（填段数和直径范围），或手动填写边界表。
- 下方有粒径段预览。

## 5. 初始与排放

颗粒有三种填法，用页面右上的分段按钮切换：

1. **对数正态模态**：每行一个模态，填数浓度、Dg（数中值直径）、σg 和各物种干质量分数（自动归一化）。
   程序按组成把每个模态归入对应类群。
2. **类群 × 粒径表**：行是类群、列是粒径段（行列名自动生成），直接填数浓度；
   另一张表填各类群的干质量分数。
3. **各物种各粒径质量**：行是物种、列是粒径段，填质量浓度；数浓度可选填，
   空着则按粒径段中值直径推算。

其他内容：
- **气体**表可筛选，● 表示可冷凝气体。
- **排放与源** 页另有排放时间廓线；气体源可“同颗粒排放”、“跟随 J(NO2)”（代替白天光化学生成）或自定义。

## 6. 后处理

计算方法与内核同名模块一致，并同时给出**类群分辨**结果和**每个粒径段合并为内混**的参考结果，
两者之差就是混合态的影响。

- **光学与辐射**：
  - 混合规则 0–3，生产配置为 2（简化壳 LUT）；
  - 输出 RRTMG 各波段消光、单次散射反照率、不对称因子，550 nm 的 BC/沙尘贡献，以及 BC 吸收增强 E_abs。
- **云活化（CCN）**：
  - 给定过饱和度的 CCN 谱；
  - 给定上升速度时，按 Abdul-Razzak & Ghan 方法求最大过饱和度和云滴数，以及各类群的活化比例。
- **非均相化学**：N2O5、HO2、NO3、NO2 的吸收速率 k、有效 γ、寿命。规则有三种：
  - CESM 固定 γ；
  - 可编辑的“物种 γ 表”（行是物种、列是气体）；
  - N2O5 的 Bertram & Thornton 参数化，可叠加有机包覆限制。

勾选“启用”后，运行结束会自动计算。对已有运行，也可在结果页按当前设置重新计算。

## 7. 运行与结果

- 填运行名称，点 **▶ 运行**；左侧列表显示进度。点选某次运行查看结果。
- 结果分页：
  - 概览：数浓度、各物种干质量、含水、气体、温湿度，在线 N2O5 结果；
  - 粒径分布：dN/dlogD、dM/dlogD，可拖动时间；
  - 混合态：各类群数浓度占比、各类群组成；
  - 光学、CCN、非均相化学。
- **下载 JSON** 可导出全部数组，自己作图分析。**载入编辑器** 可把这次运行的配置重新载入修改。

## 8. 对比实验

1. 先在①–④配好基准情景。
2. 在⑥选择要变化的维度（如 `mixing.preset`、`kernel.isorropia`、`time.substep_s`），点“添加变体”；
   也可选“自定义”，填任意配置路径和取值（如 `environment.relative_humidity` 取 `0.5, 0.7, 0.9`）。
3. 点 **▶ 运行实验组**。完成后选择指标：
   - 数浓度、PM、各物种；
   - 550 nm 消光、E_abs；
   - 各过饱和度的 CCN、各上升速度的 Nd；
   - k_het。

   图中叠加各变体曲线，表格给出终值和相对第一组的差异。

## 9. PartMC 粒子分辨模式

PartMC 版界面（右上角切到 **PartMC 粒子分辨**，或打开 `<网址>/?model=partmc`）与 SCRAM 版共用同一套
情景、配置和后处理，只是运行时改用 PartMC 逐颗粒模拟：
- 布朗凝并、排放、稀释由 PartMC 计算；
- 每个颗粒用 SCRAM 的动态 ISORROPIA 方案（v2.3 或 v1）、CESM VBS SOA 和 SOA 光解；
- 初始颗粒在本情景的粒径段范围内抽样，因此与 SCRAM 网格的初始状态一致。

1. 在①–④配好情景，⑤页的 **PartMC 设置** 卡片里可调：
   - 颗粒数（默认 10000，越多统计噪声越小，耗时近似线性增加）；
   - PartMC 时间步长（默认 60 s）；
   - 随机种子；
   - 权重指数（默认 −1，小颗粒用更少的计算颗粒代表更多实际颗粒）。
2. 点 **▶ 运行 PartMC**。运行记录里 PartMC 运行带 “PartMC” 标记。
3. 结果有两类：
   - **投影到本网格**：把每个颗粒按粒径段 × 类群归类，得到与 SCRAM 运行同格式的结果，
     “概览 / 粒径分布 / 混合态 / 光学 / CCN / 非均相化学” 各页都可直接用，便于和 SCRAM 逐项对比；
   - **粒子分辨**页（真值）：
     - 逐颗粒的混合态指数 χ（Riemer & West 2013），与投影到网格后的 χ 对比；
     - 逐颗粒 κ-Köhler 的 CCN，与网格 CCN 对比；
     - 含 BC 颗粒数和包覆比；
     - BC 质量分数 – 干粒径、κ – 干粒径二维分布（可拖动时间滑块）。
4. 在⑥点 **⚖ SCRAM NC1/NC6/NC11 对比 PartMC**，可一次跑三种 SCRAM 混合态加一个 PartMC。
   选 χ 或 CCN 指标时，图中会多一条虚线：PartMC 逐颗粒真值。
   - SCRAM 与“PartMC 投影到网格”之差，主要反映网格动力学误差；
   - “投影到网格”与“逐颗粒真值”之差，则是有限类群表示带来的误差。

说明与限制：
- PartMC 运行不包括成核和在线 N2O5 吸收，且 ISORROPIA 必须选 v2.3 或 v1；
- 共享服务器上颗粒数 ≤ 20000，且颗粒数 × 时间步数 ≤ 3×10⁷；
- 单机版不附带 PartMC：如需使用，须自行编译带 SCRAM 热力学模块的 PartMC，并用环境变量
  `PARTMC_V23` / `PARTMC_V1` 指向可执行文件，否则界面会提示 PartMC 不可用。

## 10. 常见问题

- **运行报错 “run too large for the shared server”**：缩短时长、增大子步长、减少粒径段或类群，或改用单机版。
- **动态 ISORROPIA 很慢**：默认 10 s 子步长；只看整体趋势时可试 60 s，但会引入误差。
- **v1 与 v2.3 的区别**：v2.3 把沙尘与海盐中的 Ca、K、Mg（按 CMAQ 物种分配，由内核诊断，不单独输送）纳入热力学。
- **结果文件在哪**：
  - 共享服务器上的数据在服务器的工作区内，请用结果页的“下载 JSON”导出；
  - 单机版在 `~/.scrambox/runs/<运行名>/`，包括输入、输出与 `results.npz`。
